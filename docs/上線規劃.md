# 正式上線規劃（發想筆記）

2026-11-20 記錄。看到 9upper-online.com 的版面覺得動線舒服，以下是「學它的思路、不照抄」的整理：只取結構上的優點，視覺、文案、配色都用牌桌自己的霓虹夢幻風格重做。

## 想學的地方（只學結構）
- **首頁一眼看懂**：左邊大標＋一句話說明（例：支援幾人、不用註冊），右邊就是「加入房間／建立房間」兩個分頁切換的卡片，沒有多餘步驟
- **加入／建立用分頁切換**：同一張卡片切換兩種表單，目前牌桌是上下排，正式版可改成分頁
- **怎麼玩放在主要按鈕正下方**：新朋友不用找
- **窄螢幕時選單收成右上角漢堡按鈕**：寬螢幕時是一排文字連結，視窗變窄就收成 ☰，點開是一張下拉卡片。乾淨、手機友善，正式版要做
- **每個頁面固定頁尾**：品牌、一句說明、聯絡信箱、頁面連結

## 正式版要補的頁面（內容自己寫）
- 玩法說明：每個遊戲一段（可直接用各遊戲的 desc 延伸，加圖示說明角色）
- 關於本網站：為什麼做（跟老朋友線上聚會打牌）、免費、不用註冊
- 隱私權政策：要寫清楚牌桌實際處理的資料——暱稱、頭像（只存在房間裡）、語音走 WebRTC 點對點（經 TURN 中繼時會過 Metered）、localStorage 存了什麼（暱稱、最近房間、音效設定等）、沒有帳號也沒有資料庫
- 使用條款：免費服務、不保證不斷線、不得用於賭博、使用者自行負責語音內容
- 聯絡方式：之後開一個專用信箱
- 這些頁面的內容要依牌桌的實際情況寫，不能套用別人的條款

## 遊戲名稱與授權（重要）
- 9upper-online 在關於頁寫明「玩家獨立製作、與原版桌遊作者及出版商無關、遊戲名稱與商標屬於各自權利人」，並鼓勵大家去買實體版——牌桌正式上線時也要有同樣的聲明
- 牌桌的「誰是唬爛王」刻意不用「瞎掰王」這個商品名，題庫全部自己寫，不搬原版卡片內容
- 大富翁、拉密等也一樣：不用商標名做宣傳

## 自訂網址
- GitHub Pages 本身可以免費綁自己的網域（例如 paizhuo.com），網站繼續放 GitHub，不用換主機
- 要花錢的是**網域本身**：.com 一年約 11 美元（Cloudflare 照成本價賣，續約不漲價；2026/11/1 起 .com 批發價調漲約 0.7 美元）
- 已經有 Cloudflare 帳號，可以直接在那裡買；但買網域要綁付款方式（信用卡或 PayPal），跟之前「不綁卡」的決定要一起考慮
- 綁定步驟：買網域 → DNS 設定指向 GitHub Pages → repo 設定 Custom domain → 勾選 Enforce HTTPS（之後再做）
- 注意：換網址後，大家手機上的「最近房間」、加到主畫面的捷徑都要重新加一次
